在Vue3管理使用的icon心得

前言

（日更好難……很佩服能夠日更上傳每天學習到新東西的人TT）

最近在進行 side project 時，遇到需要使用 Material icons 的需求。然而，所使用的 UI framework 並沒有內建 Material icons 的功能，因此我思考了其他引入的方式。

需求

  • 需要具備彈性修改的能力
  • 引入方式方便
  • 減少版本更新或停更帶來的問題

過程

CDN

CDN 是我認為最快速、最便利的解決方案，因為可以藉助第三方傳輸資料，減少自有伺服器的流量負擔，而且使用方式也在文件上說明得很清楚。然而，若遇到 CDN 網址無法正常連線或是安全性上的風險，我最終決定不採用這個方法。

私人使用Material icons組成的第三方套件

在搜尋「Material icons Vue」時，可以找到許多其他開發者製作的 icon 套件。雖然這類套件很方便，但由於無法保證這些作者是否會持續更新，或是否包含設計師所需的特定 icon，這選項不夠穩定。

中途感想

考量到穩定性，我決定使用下載的方式，確保專案中 icon 的存在。雖然無法預測設計師未來會增加多少 icon，但目前設計師已整理出所需的圖標清單，因此下載這些圖標是可行的。

最終

在之後我又爬了下文章，發現可透過在Vue的 SVG 元件方案來處理，把SVG當作component使用，比如說使用vite-svg-loader，但後來看了Editable SVG Icon Systems給我靈感（但我認為這裡面的方法比較適合像我漸進式（現在只有8個）新增SVG檔案的情境，如果一次性需要大量icon的使用，不如使用套件來解決問題。）
