如何在Vue網頁載入時取得header高度並避免遮擋

Ray
  2024-10-25 20:35:23 2024-10-25 20:35:23 撰寫   2024-11-08 03:12:16 2024-11-08 03:12:16 更新  
  • Vue 
 
  • Vue 
 

問題

在做個人網頁的時候，網頁的header固定浮動在最上層，以至於下面的layout都會往上跑，導致header遮住內容的問題，因此我習慣在header的下面留個空間，我想要從身為子元件的header傳它的高度給app.vue，再把main往下推，因此我需要在載入網頁的時候，就得到header的高度。

但我實際使用ref取DOM再取header的高度，或者是透過JS原生給的queryselector也選不到，後來處理爬文老半天才透過別人的寫法得到解決方案。

那這篇文章要說什麼？

其實是我回去看官網之後，才注意到這段話：
**Note that you can only access the ref after the component is mounted. **

我截了Vue官方對於生命週期說明的圖，在上面標註一下我理解的部分：

也就是說我一直在錯誤的時機點想要訪問到該DOM的資訊，但該DOM根本還沒被渲染，但又希望整個網頁能跑完時就能得到DOM的資訊。

解決的辦法

後來在網路上看到ResizeObserver的用法解決了我的煩腦，它可以在元素產生變化時重新偵測尺寸。

因此我能先讓這個元素使用這個API，等它因為渲染之後被改變，就能立刻拿到我要的高度。
